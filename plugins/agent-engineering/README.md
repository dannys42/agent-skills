# agent-engineering

A cross-agent plugin bundling tools for developing agent skills and improving
agent efficiency.

## Skills

### `optimizing-skill-development`

Chooses the smallest validation profile that covers the actual risk of a new
or changed agent skill and keeps rubric-scored evaluation evidence tied to one
artifact hash. See [docs/optimizing-skill-development.md](docs/optimizing-skill-development.md).

### `audit-token-efficiency`

Reviews a completed task for token-efficiency opportunities and records
durable findings in a `Documentation/` folder. Manual invocation only.
See [docs/audit-token-efficiency.md](docs/audit-token-efficiency.md).
