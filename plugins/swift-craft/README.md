# swift-craft

A cross-agent plugin bundling Danny Sung's Swift conventions.

## Skills

### `naming-swift-tests`

Names Swift Testing and XCTest files, suites, functions, values, fixtures,
test environments, and parameterized arguments so each test's inputs, expected
and observed values, and outcome are immediately clear.
See [docs/naming-swift-tests.md](docs/naming-swift-tests.md).

### `choosing-swift-design-patterns`

Selects among 22 common design patterns for greenfield Swift design and
existing-code review, preferring no change or a clearer Swift-native construct.
See [docs/design-patterns.md](docs/design-patterns.md).

### `organizing-swift-files`

Gives every Swift struct, class, and actor a focused file, groups related files
in concept directories, and keeps structural refactoring separate from
behavioral changes in Git history.
