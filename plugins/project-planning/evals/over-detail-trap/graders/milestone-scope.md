The roadmap details only the first milestone, and that milestone is small.

Pass when ALL of these hold:
- The first milestone is "see how well folder suggestions work on my own bookmarks" (or equivalent), and it is reached with the simplest matcher that can be measured, not with several methods compared.
- Only the first milestone's rungs have detail (question, slice, done-when). Every later milestone or horizon item is one line.
- The measurement tool the first milestone builds is small: a few commands or one report, not per-method reports, threshold sweeps, sibling-confusion analysis and timing all at once. Those may appear as one-line later items.
- No rung in the first milestone builds a second matching method, a confidence threshold, a language-model tier or any user interface for filing.

Fail if the first milestone compares several matching methods, calibrates a threshold, or if any later milestone has detailed rungs.
